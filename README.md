# Breast Cancer Classification Using LDA, QDA & Logistic Regression

## Project Overview

This project applies and compares three classification methods:
Linear Discriminant Analysis (LDA), Quadratic Discriminant Analysis (QDA),
and Logistic Regression using the Breast Cancer Wisconsin (Diagnostic) dataset.

## Objective

The objective of this project is to predict breast cancer diagnosis
and compare the performance of different classification algorithms.

## Dataset

The Breast Cancer Wisconsin (Diagnostic) dataset was obtained from
the `mlbench` package in R.

## Methods

The following classification methods were implemented:

- Linear Discriminant Analysis (LDA)
- Quadratic Discriminant Analysis (QDA)
- Logistic Regression

## Data Preprocessing

The analysis included:

- Exploratory data analysis
- Missing-value handling
- Train-test splitting
- Feature standardization

## Model Evaluation

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- ROC curve
- AUC
